                    功能可用性

                    比较 Claude Code 功能在 Anthropic 订阅计划、Anthropic Console、Amazon Bedrock、AWS 上的 Claude Platform、Google Cloud 的 Agent Platform 和 Microsoft Foundry 中的可用性。

                    Claude Code CLI 和所有本地运行的功能在每个提供商上的工作方式完全相同。有关每个提供商的设置说明，请参阅企业部署概述。要直接跳到您的提供商上缺少的功能，请参阅按提供商汇总选项卡。

                    在下表中，✓ 表示可用，✗ 表示不可用，"See note"链接到脚注以获取部分支持。✓ 后面的限定符将可用性缩小到该子集，"Admin-enabled"表示该功能处于关闭状态，直到组织管理员将其打开。

                    按模型提供商的可用性

                    您的身份验证方式决定了 Claude Code 可以访问哪些功能。有关您的提供商上缺少的内容的单一列表，请参阅按提供商汇总选项卡。要在表格中找到您的列：

                    • Claude 订阅：您使用 claude.ai 账户登录 Pro、Max、Ultra、Team 或 Enterprise 套餐
                    • Anthropic Console：您使用 Anthropic API 密钥进行身份验证，或者在没有 API 密钥的情况下登录 Console 账户
                    • Amazon Bedrock：您从 Amazon Bedrock 模型目录中使用 Claude 模型并设置 CLAUDE_CODE_USE_BEDROCK。Mantle 端点（CLAUDE_CODE_USE_MANTLE）由此列涵盖
                    • Claude Platform on AWS：您通过 AWS Marketplace 购买了 Claude，但调用 Anthropic API，并设置 CLAUDE_CODE_USE_ANTHROPIC_AWS
                    • Google Cloud's Agent Platform：由 Google 运营；您设置 CLAUDE_CODE_USE_VERTEX
                    • Microsoft Foundry：由 Anthropic 运营；您设置 CLAUDE_CODE_USE_FOUNDRY

                    每个提供商都可用的功能

                    这些在每个提供商上都有效：

                    • CLI 和 Agent SDK
                    • VS Code 和 JetBrains 扩展
                    • Subagents、hooks、commands 和 skills
                    • CLAUDE.md memory、plugins 和 MCP servers
                    • Checkpoints、sandboxing 和 Workflows
                    • OpenTelemetry metrics 和托管设置文件

                    这些有提供商特定的差异：

                    • MCP 服务器：来自 claude.ai 的连接器仅在您的 claude.ai 订阅是活跃身份验证方法时加载。工具搜索在 Microsoft Foundry 部署在 Azure 上时不受支持。在 Google Cloud's Agent Platform 上，早于 Claude Opus 4.5、Claude Sonnet 4.5 和 Claude Haiku 4.5 的模型不支持工具搜索
                    • Subagents：当主对话运行 Fable 时，如果使用 Claude 订阅、Anthropic Console 账户或通过 ANTHROPIC_BASE_URL 访问的 LLM gateway，内置的 Explore subagent 会在 Opus 上运行。在其他提供商（包括 Claude Platform on AWS）上，它在 Fable 上运行
                    • Commands：
                    • /design-sync 和 /import 及其 claude import 子命令形式在 Amazon Bedrock、Google Cloud's Agent Platform、Microsoft Foundry 和 Claude Platform on AWS 上不可用，以及通过 Claude apps gateway
                    • /voice 需要 claude.ai 账户
                    • /list-agents 及其别名 /peers 仅在启用了跨会话消息传递的会话中可用

                    需要 Claude 订阅的功能

                    这些需要使用 claude.ai 账户登录，无法通过 Anthropic Console API 密钥或第三方提供商访问：

                    • 云端会话和移动设备上的 Claude Code
                    • Slack 中的 Claude Code：Pro、Max 和 Ultra 套餐
                    • Claude Code Desktop
                    • 云端定时任务（/schedule）
                    • Ultrareview
                    • Code Review：Team 和 Enterprise 计划
                    • Remote Control
                    • Chrome 扩展
                    • Computer use：Pro、Max 和 Ultra 套餐
                    • Artifacts：Pro、Max、Ultra、Team 和 Enterprise 套餐
                    • Voice dictation

                    Desktop 是部分例外：网关路由可以在应用中或由管理员配置。Claude Desktop on 3P 还可以在 Amazon Bedrock、Google Cloud's Agent Platform、Microsoft Foundry 或自托管 LLM 网关上运行 Code 选项卡。它还可以使用 Anthropic Console API 密钥在 Claude API 上运行 Code 选项卡。有关这些功能的按计划可用性，请参阅按订阅计划的可用性。

                    说明

                    如果您通过 LLM gateway 进行身份验证，功能可用性与网关转发到的基础提供商相匹配，除了 Claude Code 本身关闭的功能。每当 ANTHROPIC_BASE_URL 指向 api.anthropic.com 以外的主机时，Claude Code 会关闭功能，例如 Remote Control 和 server-managed settings，无论网关转发什么。某些仅限 Anthropic 的功能，例如 Advisor，仅在网关将请求完整转发到 Anthropic API 时才有效。

                    有关 Claude Code 发送的请求在 Amazon Bedrock 或 Agent Platform 格式网关、ANTHROPIC_BASE_URL 网关和 Claude apps gateway 登录之间如何不同，请参阅按连接方法的客户端行为。

                    按提供商汇总

                    每个选项卡列出了该提供商上不可用或部分支持的内容，以及存在替代方案的地方。未列出的所有内容的工作方式与 Claude 订阅上相同，除了上面注明的提供商特定的差异。在 Amazon Bedrock、Google Cloud's Agent Platform、Microsoft Foundry 和 Claude Platform on AWS 上，错误报告和遥测到 Anthropic 默认处于关闭状态。请参阅按 API 提供商的默认行为了解哪些流量仍然到达 Anthropic 以及如何选择退出。

                    [tab] Amazon Bedrock

                    不可用： 所有需要 Claude 订阅的功能，加上 web search、fast mode、Advisor、Channels、analytics dashboard、server-managed settings 和 /design-sync 和 /import 命令。

                    部分支持：

                    • Desktop：仅通过 Claude Desktop on 3P
                    • Auto mode：仅 Sonnet 5 或更高版本、Opus 4.7 或更高版本、Haiku 5.5 以及 Fable 模型
                    • Cross-session messaging：仅在此机器上的您的会话之间 5
                    • Zero Data Retention：受您的 AWS 协议约束

                    替代方案： 对于调度，使用 /loop 而不是 /schedule。对于云会话，使用 GitHub Actions 或 GitLab CI/CD。对于网络查询，使用带有特定 URL 的 WebFetch tool。

                    [tab] Claude Platform on AWS

                    不可用： 所有需要 Claude 订阅的功能，加上 fast mode、Advisor、Channels、GitHub Actions、analytics dashboard、server-managed settings 和 /design-sync 和 /import 命令。

                    Amazon Bedrock 不可用的地方可用： web search。

                    部分支持：

                    • Cross-session messaging：仅在此机器上的您的会话之间 5

                    替代方案： 对于调度，使用 /loop 而不是 /schedule。对于云会话，使用 GitLab CI/CD。

                    [tab] Google Cloud's Agent Platform

                    不可用： 所有需要 Claude 订阅的功能，加上 fast mode、Advisor、Channels、analytics dashboard、server-managed settings 和 /design-sync 和 /import 命令。

                    部分支持：

                    • Desktop：通过托管设置或 Claude Desktop on 3P
                    • Web search：Opus 4、Sonnet 4、Haiku 4.5 及更高版本的模型
                    • Auto mode：仅 Sonnet 5 或更高版本、Opus 4.7 或更高版本、Haiku 5.5 以及 Fable 模型
                    • Cross-session messaging：仅在此机器上的您的会话之间 5
                    • Zero Data Retention：受您的 Google Cloud 协议约束

                    替代方案： 对于调度，使用 /loop 而不是 /schedule。对于云会话，使用 GitHub Actions 或 GitLab CI/CD。

                    [tab] Microsoft Foundry

                    不可用： 所有需要 Claude 订阅的功能，加上 fast mode、Advisor、Channels、GitLab CI/CD、analytics dashboard、server-managed settings 和 /design-sync 和 /import 命令。

                    部分支持：

                    • Desktop：仅通过 Claude Desktop on 3P
                    • Auto mode：仅 Sonnet 5 或更高版本、Opus 4.7 或更高版本、Haiku 5.5 以及 Fable 模型
                    • Cross-session messaging：仅在此机器上的您的会话之间 5
                    • Zero Data Retention：受您的 Azure 协议约束

                    替代方案： 对于调度，使用 /loop 而不是 /schedule。对于云会话，使用 GitHub Actions。

                    [tab] Anthropic Console

                    不可用： 所有需要 Claude 订阅的功能。

                    按提供商变化的 CLI 功能中的所有内容都可用，除了使用 Claude Opus 5 或 Claude Opus 4.8 的 fast mode 需要预配置访问。在 claude.ai Team 或 Enterprise 组织中配置的 Server-managed settings 不会作用于使用 Console API 密钥进行身份验证的会话。有关如何覆盖这些会话，请参阅平台可用性。

                    部分支持：

                    • Desktop：通过结合 Claude API 使用的 Claude Desktop on 3P
