各开发模式支持的绑定

哪些绑定能在本地模拟，哪些必须连远程资源，哪些只能在远程开发中使用。

本地开发 原文更新于 2026-06-25 对应页面：local-development/bindings-per-env

本地开发

本地模拟（Local simulations）：本地开发时，你的 Worker 代码始终在本地执行，而绑定默认连接到本地模拟的资源。wrangler dev 与 Cloudflare Vite 插件都支持这种方式。

远程绑定连接（Remote binding connections）：允许你按单个绑定连接到远程资源。wrangler dev 与 Cloudflare Vite 插件都支持这种方式。

远程开发

远程开发时，你的 Worker 代码会被上传到 Cloudflare 的基础设施上执行，绑定始终连接远程资源。我们建议改用「本地开发 + 远程绑定连接」，迭代和调试都更快。

这种方式仅支持 wrangler dev --remote——没有对应的 Vite 插件功能。
