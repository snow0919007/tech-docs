Wrangler 与 Vite 如何选择

两套本地开发环境都能跑 Worker，区别在于构建管线与生态。

本地开发 原文更新于 2026-07-28 对应页面：local-development/wrangler-vs-vite

Wrangler 与 Cloudflare Vite 插件都提供 Workers 的本地开发环境。两者都支持后端 Worker、本地与远程绑定，以及多 Worker 应用。

选择的关键是看你项目使用的是哪套构建工具。你也可以用 Vite 插件做开发与构建，同时用 Wrangler 做部署和执行其他 Workers 命令。

能力对比

能力或工作流WranglerCloudflare Vite 插件
独立的 JavaScript 或 TypeScript Worker支持支持
全栈与后端 Worker支持支持
通过 Miniflare 做本地绑定模拟支持支持
远程绑定支持支持
多 Worker 开发支持支持
前端与 SSR 框架使用框架自身的构建产物与 Vite 驱动的框架集成
构建管线使用 Wrangler 的打包器或自定义构建使用 Vite 的转换、热更新（HMR）与插件体系
部署与资源管理支持vite build 之后交由 Wrangler 完成
Rust Worker支持不支持
Python Worker用 pywrangler 代替 wrangler不支持

怎么选

如果你的项目已经在用 Vite，或者能从它的构建管线中获益，就用 Cloudflare Vite 插件。Vite 并不只适用于前端应用，独立的后端 Worker 一样可以用。

如果项目没用 Vite，或者你偏好直接用命令行工作流，就用 wrangler dev。Wrangler 同时提供部署与资源管理命令。

对于需要访问已部署资源的本地开发，两种工具都支持远程绑定：Worker 在本地运行，而指定的绑定连接到已部署的 Cloudflare 资源。

要把已有项目迁到 Vite 插件，配置上的差异参见从 wrangler dev 迁移。
