Playground（在线演练场）

在基于浏览器的沙箱里预览和测试 Workers 代码，不需要任何配置，也不需要登录。

在线演练场 原文更新于 2026-04-23 对应页面：playground
浏览器支持

Cloudflare Workers Playground 目前仅支持 Firefox 和 Chrome 桌面版浏览器。在 Safari 中会显示 PreviewRequestFailed 错误。

试用 Cloudflare Workers 最快的方式就是打开演练场（Playground）↗。它不需要任何配置，也不需要身份验证。演练场是一个沙箱，让你能立刻在浏览器里预览和测试 Worker。

演练场使用的编辑器与登录后的正式体验是同一个。你可以在演练场里分享自己写的代码，也能把它直接部署到 Cloudflare 的全球网络上——先随意试，准备好了再上线。

workers.cloudflare.com 启动 Playground ↗

Hello Cloudflare Workers

进入演练场后，你会看到这段默认代码：

import welcome from "welcome.html";

/**
 * @typedef {Object} Env
 */

export default {
	/**
	 * @param {Request} request
	 * @param {Env} env
	 * @param {ExecutionContext} ctx
	 * @returns {Response}
	 */
	fetch(request, env, ctx) {
		console.log("Hello Cloudflare Workers!");

		return new Response(welcome, {
			headers: {
				"content-type": "text/html",
			},
		});
	},
};

这是一个多模块 Worker 的例子：它接收一个请求，往控制台打一条日志，然后返回一个响应，响应体是 welcome.html 的内容。

更多细节参见 Fetch 处理器文档。

使用演练场

当你修改默认代码时，Worker 会自动更新，右侧预览会像在浏览器里一样展示它的运行效果。如果你的 Worker 使用了 URL 路径，可以在右侧的输入框里填入路径进行访问。演练场通过 JSDoc 注释和 workers-types ↗ 提供类型检查，应用出错时还会给出易读的错误页面。

要测试原始 HTTP 请求（例如测试一个 POST 请求），切到 HTTP 标签页并点击 Send。你可以在这个面板里增删和修改请求头，也能编辑请求体。

日志查看器

演练场和 Workers 控制台里的快速编辑器，都在预览面板底部提供了一个轻量的日志查看器（log viewer），用来显示预览运行期间所有 console.log 调用的输出。

日志查看器目前支持：

  • 记录原始值、对象和数组。
  • 在每次运行之间清空日志输出。

目前，日志查看器还不支持记录类实例及其属性（例如 request.url）。

如果你需要完整的调试能力和更完整的开发体验，可以在本地使用 Wrangler。想把控制台里已有的 Worker 拉到本地开发：注册账号，部署该 Worker 之后执行 wrangler init --from-dash 命令。

分享

要分享你的作品，点击屏幕右上角的 Copy Link。它会把一个唯一 URL 复制到剪贴板，你可以发给任何人。这些链接不会过期，可以收藏、随时分享。打开分享链接的人会看到带着这份代码与预览的演练场。

部署

你可以直接从演练场部署 Worker。如果已登录，可以在部署前复核这个 Worker；如果没登录，会先走一遍首次使用者的引导流程，然后才能复核并部署。

部署完成后，你的 Worker 会获得一个唯一 URL，几乎立刻就能在 Cloudflare 全球网络上访问。此后你可以为它添加自定义域名、存储资源等等。
