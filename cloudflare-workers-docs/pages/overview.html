Cloudflare Workers

一个无服务器（serverless）平台：只需一条命令，就能在 Cloudflare 的全球网络上构建、部署和扩展应用——不用管理基础设施，也不用写复杂的配置。

概览 原文更新于 2026-10-08 对应页面：workers/index

使用 Cloudflare Workers，你可以做到：

  • 在世界任何地方交付快速且高可靠的性能
  • 用你惯用的框架构建全栈应用，包括 React、Vue、Svelte、Next、Astro、React Router、fate 等
  • 使用你偏好的语言，包括 JavaScript、TypeScript、Python、Rust 等
  • 借助内置的可观测性获得深度可见性与洞察
  • 免费起步，并随规模按灵活的计费方式成长

开始你的第一个项目：

在控制台一键开始部署一个模板 ↗ 推荐路径用 Wrangler CLI 部署 →

用 Workers 构建

前端应用

把静态资源部署到 Cloudflare 的 CDN 与缓存上，实现快速渲染。

后端应用

构建 API 并连接数据存储，配合 Smart Placement（智能部署位置）优化延迟。

无服务器 AI 推理

运行大语言模型（LLM）、生成图像等，由 Workers AI ↗ 提供算力。

后台任务

调度 cron 定时任务、运行持久化的 Workflows ↗，并与 Queues ↗ 集成。

可观测性与监控

通过实时日志与分析监控性能、排查问题、分析流量。

与 Workers 集成

通过绑定（Bindings）连接数据库、API、存储等外部服务，几行代码就能启用相应能力。

存储（Storage）

Durable Objects ↗

可扩展的有状态存储，用于实时协调。

D1 ↗

为快速全球查询而生的无服务器 SQL 数据库。

KV ↗

低延迟键值存储，读取命中边缘缓存。

Queues ↗

保证投递，且不收取出口带宽费用。

Hyperdrive ↗

连接你已有的外部数据库，查询加速并在边缘缓存。

计算（Compute）

Workers AI ↗

由无服务器 GPU 驱动的机器学习模型。

Workflows ↗

持久、长时间运行的操作，支持自动重试。

Vectorize ↗

用于 AI 语义搜索的向量数据库。

R2 ↗

零出口费用的对象存储，数据访问更经济。

Browser Run ↗

可编程的无服务器浏览器实例。

媒体（Media）

Cache / CDN ↗

全球缓存，带来高性能、低延迟的分发。

Images ↗

用一套 API 打通的图像基础设施。
