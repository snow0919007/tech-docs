术语表

Workers 文档中反复出现的术语，此处统一给出释义与译法。

术语表 原文更新于 2026-04-23 对应页面：glossary
术语释义
Auxiliary Worker
辅助 Worker		 通过 Workers Vitest 集成在本地创建的 Worker，它运行在与测试运行器不同的 isolate 中，全局作用域也不同。
binding
绑定		 绑定让 Worker 能够与 Cloudflare 开发者平台上的资源交互。
C3 C3 是一个命令行工具，用来帮你在 Cloudflare 上搭建并部署新应用。
CPU time
CPU 时间		 CPU 时间指在单次请求处理中，中央处理器（CPU）真正用于执行计算的时间量。
Cron Triggers
Cron 触发器		 Cron 触发器让用户把一条 cron 表达式映射到一个 Worker（通过 scheduled() 处理器），从而按计划执行 Worker。
D1 D1 ↗ 是 Cloudflare 原生的无服务器数据库。
deployment
部署		 部署记录当前正在对外提供流量的 Worker 版本。
Durable Objects Durable Objects ↗ 是一个全局分布式的协调 API，提供强一致性的存储。
duration
持续时间		 持续时间是对挂钟时间的度量——即一次 Worker 调用从开始到结束的总时长。
environment
环境		 环境让你为同一个 Worker 应用按环境部署不同配置。仅在配合 Wrangler 配置文件时可用。
environment variable
环境变量		 环境变量是一类绑定，用来把文本字符串或 JSON 值附加到 Worker 上。
handler
处理器		 处理器是 Worker 上的方法，能够接收并处理外部输入，并可从 Worker 之外被调用。
isolate
隔离实例		 Isolate 是一种轻量上下文，为你的代码提供可访问的变量，以及一个安全的执行环境。
KV Workers KV ↗ 是 Cloudflare 的键值数据存储。
module Worker
模块化 Worker		 指用模块语法编写的 Worker。
origin
源站		 源站 ↗一般指 Cloudflare 背后承载你应用的那台 Web 服务器。
Pages Cloudflare Pages ↗ 是 Cloudflare 用于构建和部署全栈应用的产品。
Queues Queues ↗ 与 Cloudflare Workers 集成，让你能构建保证投递的应用。
R2 R2 ↗ 是兼容 S3 的分布式对象存储，目标是消除跨云共享数据的障碍。
rollback
回滚		 回滚是把一个更早的部署重新发布到 Cloudflare 全球网络的方式。
secret
密钥		 密钥是一类绑定，用来把加密的文本值附加到 Worker 上。
service Worker
Service Worker 写法		 指用 service worker 语法编写的 Worker。
subrequest
子请求		 子请求指 Worker 使用 Fetch API 向互联网资源发出的任何请求，或向 R2、KV、D1 等其他 Cloudflare 服务发出的请求。
Tail Worker Tail Worker 接收其他 Worker（称为生产者 Worker）的执行信息，例如 HTTP 状态、传给 console.log() 的数据或未捕获的异常。
V8 Chrome V8 是一个 JavaScript 引擎 ↗，也就是说它负责执行 JavaScript 代码。
version
版本		 版本由 Worker 的 Wrangler 文件中的代码状态与配置状态共同定义。
wall-clock time
挂钟时间		 挂钟时间是一次 Worker 调用从开始到结束的总时长。
workerd workerd ↗ 是一个 JavaScript / Wasm 服务端运行时，与支撑 Cloudflare Workers 的代码同源。
Wrangler Wrangler 是 Cloudflare 开发者平台的命令行接口（CLI），用于管理由该平台创建的各类项目（例如 Workers）。
wrangler.toml / wrangler.json / wrangler.jsonc 用于定制 Worker 或 Pages Function 的开发与部署设置的配置文件。
