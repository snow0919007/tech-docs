支持的协议

Workers 平台支持的协议与接口一览，区分入站与出站。

参考 原文更新于 2026-10-13 对应页面：reference/protocols

Cloudflare Workers 支持下列协议与接口：

协议入站（Inbound）出站（Outbound）
HTTP / HTTPS 用 fetch() 处理器处理传入的 HTTP 请求 用 fetch() API 发起 HTTP 子请求
直连 TCP socket 用 connect() 处理器处理从另一个 Worker 转发过来的 TCP 连接。直接接收外部 TCP 连接的支持即将推出 ↗ 用 connect() API 建立出站 TCP 连接
WebSockets 用 WebSocket API 接受传入的 WebSocket 连接 —
HTTP/3（QUIC） 在 Cloudflare 控制台 ↗的 Speed > Settings > Protocol Optimization 中为你的区域（zone）↗启用 HTTP/3 ↗ 之后，即可接收基于 HTTP/3 的入站请求 —
SMTP 用 Email Workers ↗ 处理并转发邮件，无需自己管理与 SMTP 邮件服务器之间的 TCP 连接 Email Workers ↗
