模板与起步仓库

模板是专门设计成「新项目起点」的 GitHub 仓库。

快速开始 原文更新于 2026-08-10 对应页面：get-started/quickstarts

模板（Templates）是一批 GitHub 仓库，用途是作为新建 Cloudflare Workers 项目的起点。你可以在 Cloudflare 控制台浏览完整的模板集合，然后部署最贴合自己使用场景的那一个。

Cloudflare 控制台 部署一个模板 ↗

用命令行从模板起步

除了在控制台点选，也可以在终端用 C3 直接以某个仓库作为模板创建项目：

npm create cloudflare@latest -- --template <SOURCE>

其中 <SOURCE> 支持 user/repo、完整的 GitHub 地址、子目录（user/repo/some-template）、分支（user/repo#canary）、提交哈希，以及 bitbucket: 与 gitlab: 前缀。详见通过 CLI 创建。

模板至少要包含什么

自定义模板目录必须包含 package.json、wrangler.jsonc，以及一个被 wrangler.jsonc 引用的 src/ 目录（内含 worker 脚本）。
