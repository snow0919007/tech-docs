通过控制台创建

不安装任何本地工具，直接在浏览器里创建并发布一个 Workers 应用。

快速开始 原文更新于 2026-06-25 对应页面：get-started/dashboard

按本指南操作，你将在 Cloudflare 控制台（dashboard）中创建一个 Workers 应用。

试试在线演练场

想最快地试用 Cloudflare Workers，可以直接打开在线演练场（Playground）↗。它不需要任何配置，可以立刻在浏览器里预览和测试一个 Worker。

前置条件

如果还没有账号，请先创建一个 Cloudflare 账号 ↗。

操作步骤

要创建一个新的 Workers 应用：

  1. 在 Cloudflare 控制台中进入 Workers & Pages 页面。前往 Workers & Pages ↗
  2. 选择 Create application（创建应用）。在这里你可以：
    • 从可直接用于生产的模板库中挑选一个
    • 导入你自己账户下已有的 Git 仓库
    • 让 Cloudflare 克隆并初始化一个包含 Workers 应用的公开仓库
  3. 连接到你选定的 Git 服务商 ↗ 之后，配置项目并选择 Deploy（部署）。
  4. Cloudflare 会启动一次新的构建与部署。部署完成后，你可以用它分配的 workers.dev 子域预览这个 Worker。

继续开发

在控制台中创建的应用会自动接好 Git，帮你快速启动开发流程。要在自己的仓库上继续开发，可以运行：

# 将仓库克隆到本地
git clone <git repo URL>

# 确认你位于仓库根目录
cd <directory>

接下来，你可以在本地开发环境中运行 Wrangler，预览并测试改动。准备发布时，运行：

# 把文件加入 git 跟踪
git add .

# 提交改动
git commit -m "your message"

# 推送到你的 Git 服务商
git push origin main

还可以做这些事：

  • 浏览示例与教程找灵感。
  • 配置绑定（bindings），让 Worker 能与其他资源交互、解锁新能力。
  • 学习如何测试与调试你的 Worker。
  • 了解 Workers 的限额与计费。
