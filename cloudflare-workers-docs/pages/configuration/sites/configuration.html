Workers Sites 配置

bucket、include、exclude 三个字段，决定哪些静态文件被上传。

配置 原文更新于 2026-04-23 对应页面：configuration/sites/configuration
请改用 Workers 静态资源

托管全栈应用请用 Workers 静态资源，而不是 Workers Sites。Workers Sites 在 Wrangler v4 中已被废弃，Cloudflare Vite 插件也不支持它。新项目不要使用 Workers Sites。

Workers Sites 需要最新版本的 Wrangler ↗。

Wrangler 配置文件

Workers Sites 在 Wrangler 文件里有几个专属配置项：

  • bucket（必填）：存放静态资源的目录，路径相对于 Wrangler 配置文件。例如 bucket = "./public"。
  • include（可选）：一组 gitignore 风格的匹配模式，指定你只想上传 bucket 里的哪些文件或目录。例如 include = ["upload_dir"]。
  • exclude（可选）：一组 gitignore 风格的匹配模式，指定你不想上传的文件或目录。例如 exclude = ["ignore_dir"]。

关于可选的 include 与 exclude，见下文忽略部分静态资源。

注意

如果项目使用了环境，请把 site 放在任何环境专属配置块之上。

{
	"$schema": "./node_modules/wrangler/config-schema.json",
	"name": "docs-site-blah",
	"site": {
		"bucket": "./public"
	},
	"env": {
		"production": {
			"name": "docs-site",
			"route": "https://example.com/docs*"
		},
		"staging": {
			"name": "docs-site-staging",
			"route": "https://staging.example.com/docs*"
		}
	}
}
"$schema" = "./node_modules/wrangler/config-schema.json"
name = "docs-site-blah"

[site]
bucket = "./public"

[env.production]
name = "docs-site"
route = "https://example.com/docs*"

[env.staging]
name = "docs-site-staging"
route = "https://staging.example.com/docs*"

存储限额

对特别大的页面，Workers Sites 可能不适用：单个页面或文件上限为 25 MiB。

忽略部分静态资源

Workers Sites 依赖 Wrangler ↗，请务必使用最新版本。

有时你并不想上传某些静态资源。Workers Sites 可以配置忽略特定文件或目录，逻辑类似 Cargo 的可选 include/exclude 字段 ↗。也就是说，声明上传哪些目录项时，用的是 gitignore 语义。

只包含某些文件/目录

如果你只想上传 bucket 里特定的一组文件或目录，可以在 Wrangler 文件的 [site] 段加 include：

{
	"site": {
		"bucket": "./public",
		"include": [ // must be an array.
			"included_dir"
		]
	}
}
[site]
bucket = "./public"
include = [ "included_dir" ]

Wrangler 之后只会上传与 include 数组中模式匹配的文件或目录。

排除文件/目录

如果要排除 bucket 里的某些文件或目录，可以在 [site] 段加 exclude：

{
	"site": {
		"bucket": "./public",
		"exclude": [ // must be an array.
			"excluded_dir"
		]
	}
}
[site]
bucket = "./public"
exclude = [ "excluded_dir" ]

向 Workers KV 上传资源时，Wrangler 会忽略与 exclude 数组中模式匹配的文件或目录。

include 优先于 exclude

同时提供 include 与 exclude 时，以 include 为准，exclude 被忽略。

默认忽略的项

Wrangler 始终会忽略：

  • node_modules
  • 隐藏文件与隐藏目录
  • 符号链接

关于 include/exclude 模式

这些模式的标准写法见 gitignore 文档 ↗。
