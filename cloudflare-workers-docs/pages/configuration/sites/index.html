Workers Sites

把静态站点直接部署到 Workers 上的旧方案——新项目请改用 Workers 静态资源。

配置 原文更新于 2026-04-23 对应页面：configuration/sites
请改用 Workers 静态资源

托管全栈应用请用 Workers 静态资源，而不是 Workers Sites。Workers Sites 在 Wrangler v4 中已被废弃，Cloudflare Vite 插件也不支持它。新项目不要使用 Workers Sites。

Workers Sites 让开发者把静态应用直接部署到 Workers 上。它可用于部署由静态站点生成器（如 Hugo ↗、Gatsby ↗）构建的应用，也可用于 Vue ↗、React ↗ 这类前端框架产出的应用。

按目标项目的现状，从下面三种方式中选一种：

1. 从零开始

如果你要开一个全新项目，这份快速上手指南会帮你搭好基础设施，把一个 HTML 网站部署到 Workers。

从零开始 →

2. 部署已有的静态站点

如果你已有项目或静态资源想用 Workers 部署，这份指南会帮你安装 Wrangler 并为项目配置 Workers Sites。

从已有静态站点开始 →

3. 给已有 Worker 项目加上静态资源

如果你已有部署在 Cloudflare 上的 Worker，这份指南会演示如何在现有代码库上启用 Workers Sites。

从已有 Worker 开始 →

注意

Workers Sites 构建在 Workers KV 之上，可能会产生用量费用。详见计费。
