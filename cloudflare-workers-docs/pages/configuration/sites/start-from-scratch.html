从零创建一个 Sites 项目

克隆官方模板，五步把 HTML 站点部署到 Workers Sites。

配置 原文更新于 2026-04-23 对应页面：configuration/sites/start-from-scratch
请改用 Workers 静态资源

托管全栈应用请用 Workers 静态资源，而不是 Workers Sites。Workers Sites 在 Wrangler v4 中已被废弃，Cloudflare Vite 插件也不支持它。新项目不要使用 Workers Sites。

本指南演示如何从零快速开一个 Workers Sites 项目。

开始

  1. 确认已安装最新版本的 git ↗ 与 Node.js ↗。
  2. 在终端里克隆 worker-sites-template 起始仓库。下面的例子会创建一个叫 my-site 的项目： 
    git clone --depth=1 --branch=wrangler2 https://github.com/cloudflare/worker-sites-template my-site
  3. 运行 npm install 安装全部依赖。
  4. 运行 wrangler dev 预览站点： 
    wrangler dev
  5. 部署到 Cloudflare： 
    npx wrangler deploy

项目结构

模板项目包含这些文件与目录：

  • public：项目的静态资源，默认包含一个 index.html 与一个 favicon.ico。
  • src：为提供这些资源而配置的 Worker。通常不必改动；若想看它如何工作或给 Worker 加功能，可以编辑 src/index.ts。
  • wrangler.jsonc：项目配置。其中 bucket 属性告诉 Wrangler 去哪儿找静态资源（例如 site = { bucket = "./public" }）。
  • package.json / package-lock.json：定义所需的 Node.js 依赖。

定制 wrangler.jsonc

  • 把 name 改成你的项目名： 
    {
  "$schema": "./node_modules/wrangler/config-schema.json",
  "name": "my-site"
}
    "$schema" = "./node_modules/wrangler/config-schema.json"
name = "my-site"
  • 建议把 compatibility_date 更新为当天日期，以使用最新的 Workers 特性： 
    {
  "compatibility_date": "yyyy-mm-dd"
}
    compatibility_date = "yyyy-mm-dd"
  • 把站点部署到你自己拥有、且已接入 Cloudflare 区域的自定义域名： 
    {
  "route": "https://example.com/*"
}
    route = "https://example.com/*"
注意

如何正确配置 route，见路由文档。
