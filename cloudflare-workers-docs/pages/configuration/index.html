配置

Worker 的项目设置、绑定与部署选项，都写在这里。

配置 原文更新于 2026-09-30 对应页面：configuration

Worker 配置定义了项目设置、绑定与部署选项。可以使用 cloudflare.config.ts ↗ 做带类型的程序化配置（该格式目前处于公开测试阶段）。

你也可以继续用 Wrangler 配置文件，配合 Wrangler 与受支持的构建工具使用。

关于 Wrangler 的更多信息，见 Wrangler。

Cloudflare Access

要求访问者先登录，才能打开 Worker、预览部署或账户下全部 Worker。

兼容性日期

为项目选定一个具体的 Workers 运行时版本。

兼容性标志

单独开启或关闭运行时的某些行为。

Cron 触发器

让 Worker 按计划被自动执行。

环境变量

以绑定形式把文本或 JSON 值附加到 Worker 上。

集成

接入第三方服务、API 与外部服务。

多部分上传元数据

用 JSON 元数据描述配置，配合表单上传脚本。

Page Rules 与 Workers

Page Rules 与 Workers 之间的相互影响。

部署位置（Placement）

控制 Worker 在哪里运行，以降低延迟。

路由与域名

用路由、自定义域名或 workers.dev 子域对外提供访问。

密钥

存放 API key、令牌等敏感信息。

Workers Sites

旧的静态站点方案；新项目请改用 Workers 静态资源。

绑定（Bindings）

可用的各类绑定总览。
