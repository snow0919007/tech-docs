路由与域名

把 Worker 接到一个外部端点，让它能被互联网访问。

配置 原文更新于 2026-04-23 对应页面：configuration/routing

要让 Worker 接收入站 HTTP 请求，必须把它连接到一个外部端点，使其能被互联网访问。

共有三种路由方式：

  • 自定义域名（Custom Domains）：路由到 Cloudflare 区域内的某个域名或子域（例如 example.com 或 shop.example.com），此时 Worker 就是源站。
  • 路由（Routes）：在 Cloudflare 区域里设置的路由，如果你有源站服务器，它位于 Worker 之后，由 Worker 与它通信。
  • workers.dev：每个 Worker 创建时会自动生成一个 workers.dev 子域路由，方便你快速上手。你也可以选择禁用它。

我该用哪种

生产环境的 Worker 建议跑在 Workers 路由或自定义域名上，而不是 workers.dev 子域。你的 workers.dev 子域按 免费网站 ↗对待，定位于个人或兴趣项目，不适合承载关键业务。

当 Worker 就是你应用的源站时，推荐用自定义域名。与路由不同，自定义域名还可以在同一区域内通过 fetch() 调用。

当应用的源站服务器在 Cloudflare 之外时，推荐用路由。注意路由不能作为同区 fetch() 调用的目标。
