集成

Worker 与数据库、第三方 API、外部服务之间的接法。

配置 原文更新于 2026-04-23 对应页面：configuration/integrations

Cloudflare Workers 的关键能力之一，就是与其他服务和产品集成。本文说明 Workers 可用的集成类型，并给出使用步骤。

集成类型

Cloudflare Workers 提供以下几类集成：

  • 数据库：Worker 可以接入各类数据库，包括 SQL 与 NoSQL。这样你就能在自己的 Worker 代码里直接读写数据库。
  • API：Worker 可以对接外部 API，在代码中使用这些 API 暴露的数据与功能。
  • 第三方服务：Worker 可以接入范围很广的第三方服务，例如支付网关、身份认证服务等，从而在代码里用上它们。

如何使用集成

使用任何一类集成，步骤都是：

  • 确定要用哪种集成，并准备好对应的账号与凭据。
  • 在 Worker 代码中导入该集成所需的库或模块。
  • 用提供的 API 与函数连接该集成，访问其数据或功能。
  • 用 wrangler secret put <KEY> 把必要的密钥与令牌以密钥（secret）形式存好。

提示与最佳实践

  • 保护集成与敏感数据。尽可能使用安全的认证与授权机制，并确认所引入的库来源可靠。
  • 用缓存提升性能，同时减轻外部服务的压力。
  • 用服务绑定把 Worker 拆成面向服务的架构，让应用更模块化、更易维护、性能更好。
  • 与外部 API、服务通信时使用自定义域名：它会代你创建 DNS 记录，并把 Worker 当作一个应用（而不是代理）来对待。
