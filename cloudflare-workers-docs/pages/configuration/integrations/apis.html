对接第三方 API

用 fetch API 调第三方接口，把返回数据接进你的响应。

配置 原文更新于 2026-04-23 对应页面：configuration/integrations/apis

在 Cloudflare Workers 里对接第三方 API，就是用 fetch API 向该 API 端点发 HTTP 请求，再用返回的数据改写或加工你的内容。

举例来说，想接入一个天气 API，就向它的端点发 fetch 请求取回当前天气数据，再用这些数据在网站上显示当前天气。

发起 fetch() 请求，把下面的代码加到项目的 src/index.js：

async function handleRequest(request) {
	// Make the fetch request to the third party API endpoint
	const response = await fetch("https://weather-api.com/endpoint", {
		method: "GET",
		headers: {
			"Content-Type": "application/json",
		},
	});

	// Retrieve the data from the response
	const data = await response.json();

	// Use the data to modify or manipulate your content as needed
	return new Response(data);
}

认证

如果该 API 需要认证，用 Wrangler 的密钥功能安全存放凭据。在你的 Workers 项目里执行：

wrangler secret put SECRET_NAME

然后在代码里这样取值：

const secretValue = env.SECRET_NAME;

接着用这个密钥值向外部服务做认证。例如外部服务用 API key 认证，就把它放进请求头。

对要求 mTLS 认证的服务，用 mTLS 证书出示客户端证书。

提示

  • 用 Cache API 缓存第三方 API 的数据，从而优化那些可缓存的请求。对接第三方 API，能为你的应用增添功能与特性。
  • 与外部 API 通信时使用自定义域名——它把你的 Worker 视作核心应用。
