对接外部服务

用第三方库与 SDK 连外部服务时，需要注意哪些兼容性问题。

配置 原文更新于 2026-04-23 对应页面：configuration/integrations/external-services

许多外部服务都提供库或 SDK 来调它们自己的 API。绝大部分兼容 Node.js 的库在 Workers 上开箱即用；但有一部分实现了 fs、http/net，或者访问了浏览器的 window，这些库无法直接搬到基于 V8 的 Workers 运行时上。

认证

如果服务需要认证，用 Wrangler 的密钥功能安全存放凭据。在你的 Workers 项目里执行：

wrangler secret put SECRET_NAME

然后在代码里这样取值：

const secretValue = env.SECRET_NAME;

接着用这个密钥值向外部服务做认证。例如外部服务用 API key 认证，就把密钥填进该库的配置里。

对要求 mTLS 认证的服务，用 mTLS 证书出示客户端证书。

与外部 API 通信时使用自定义域名——它把你的 Worker 视作核心应用。

译文基于 Cloudflare 官方文档 configuration/integrations/external-services 整理，仅供学习参考；产品行为以英文原文为准。
