多部分上传元数据

直接用 API 上传脚本时，配置要写进 metadata 这一部分。

配置 原文更新于 2026-10-28 对应页面：configuration/multipart-upload-metadata
注意

上传 Worker 已有新的 API，详见基础设施即代码 · Cloudflare REST API。

如果你直接调用 Workers Script Upload API ↗ 或 Version Upload API ↗，multipart/form-data 上传必须提供一个 metadata 部分。这个元数据用 JSON 描述 Worker 的配置，相当于 wrangler.toml 配置文件。

metadata 示例

{
	"main_module": "main.js",
	"bindings": [
		{
			"type": "plain_text",
			"name": "MESSAGE",
			"text": "Hello, world!"
		}
	],
	"compatibility_date": "2021-09-14"
}

更多与 Workers Script Upload API 配合使用的元数据示例，见基础设施即代码。

顶层属性

注意

上传 Worker 时，main_module 是最低要求的必填键。

  • main_module（string，必填）：包含 Worker 模块入口的那一部分的名称，例如 main.js。
  • assets（object，可选）：Worker 的静态资源配置。
    • config（object，可选）：base_path 决定静态资源可用的 URL 路径前缀；html_handling 决定 HTML 内容请求的重定向与重写；not_found_handling 决定请求未命中静态资源时的响应。
    • jwt 字段提供授权把资源附加到该 Worker 的令牌。
  • keep_assets（boolean，可选）：是否保留上一个上传版本中的资源；用于替代提供完成令牌（completion token）的做法。
  • bindings（object 数组，可选）：要在 Worker 中暴露的绑定。
  • placement（object，可选）：Worker 的智能部署位置对象。mode 字段仅支持 smart（自动放置）。
  • compatibility_date（string，可选）：兼容性日期，表示所针对的 Workers 运行时支持范围。该日期之后运行时的不兼容修复不会影响这个 Worker。强烈建议设置；否则通过 API 上传时会默认取最老的日期——任何标志生效之前（2021-11-02）。
  • compatibility_flags（string 数组，可选）：兼容性标志，开启或关闭运行时的某些特性，用于启用尚未默认的特性、或选择接受／拒绝未包含在 compatibility_date 中的具体变更。

附加属性：Workers Script Upload API

对于上传并立即部署的场景，还有以下附加顶层属性可配。

注意

除 annotations 外，这些属性在版本上传（version upload）中不可用。

  • migrations（object 数组，可选）：要应用的 Durable Objects 迁移 ↗。
  • logpush（boolean，可选）：是否为该 Worker 开启 Logpush。
  • tail_consumers（object 数组，可选）：消费该 Worker 日志的 Tail Workers。
  • tags（string 数组，可选）：用作该 Worker 标签的字符串列表。
  • annotations（object，可选）：本次上传所创建 Worker 版本的注解对象，版本上传 API 同样支持。workers/message 指定版本的自定义描述，workers/tag 指定版本的自定义标识。

附加属性：Version Upload API

对于版本上传，以下附加顶层属性可配：

  • annotations（object，可选）：该 Worker 版本的注解对象。workers/message 指定自定义描述，workers/tag 指定自定义标识，workers/alias 指定该版本的自定义别名。

绑定

Worker 通过绑定与 Cloudflare 开发者平台上的资源交互。下面的 JSON 示例展示如何在 metadata 部分添加绑定：

{
	"bindings": [
		{
			"type": "ai",
			"name": "<VARIABLE_NAME>"
		},
		{
			"type": "analytics_engine",
			"name": "<VARIABLE_NAME>",
			"dataset": "<DATASET>"
		},
		{
			"type": "assets",
			"name": "<VARIABLE_NAME>"
		},
		{
			"type": "browser_rendering",
			"name": "<VARIABLE_NAME>"
		},
		{
			"type": "d1",
			"name": "<VARIABLE_NAME>",
			"id": "<D1_ID>"
		},
		{
			"type": "durable_object_namespace",
			"name": "<VARIABLE_NAME>",
			"class_name": "<DO_CLASS_NAME>"
		},
		{
			"type": "hyperdrive",
			"name": "<VARIABLE_NAME>",
			"id": "<HYPERDRIVE_ID>"
		},
		{
			"type": "kv_namespace",
			"name": "<VARIABLE_NAME>",
			"namespace_id": "<KV_ID>"
		},
		{
			"type": "mtls_certificate",
			"name": "<VARIABLE_NAME>",
			"certificate_id": "<MTLS_CERTIFICATE_ID>"
		},
		{
			"type": "plain_text",
			"name": "<VARIABLE_NAME>",
			"text": "<VARIABLE_VALUE>"
		},
		{
			"type": "queue",
			"name": "<VARIABLE_NAME>",
			"queue_name": "<QUEUE_NAME>"
		},
		{
			"type": "r2_bucket",
			"name": "<VARIABLE_NAME>",
			"bucket_name": "<R2_BUCKET_NAME>"
		},
		{
			"type": "secret_text",
			"name": "<VARIABLE_NAME>",
			"text": "<SECRET_VALUE>"
		},
		{
			"type": "service",
			"name": "<VARIABLE_NAME>",
			"service": "<SERVICE_NAME>",
			"environment": "production"
		},
		{
			"type": "vectorize",
			"name": "<VARIABLE_NAME>",
			"index_name": "<INDEX_NAME>"
		},
		{
			"type": "version_metadata",
			"name": "<VARIABLE_NAME>"
		}
	]
}
